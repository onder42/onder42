##  Featured Project

### **Custom 8-Bit CPU Control Unit & Bus Emulator**
A low-level hardware-software co-design project implementing a discrete-component computer architecture emulation. This system models a custom 8-bit CPU control unit, instruction register, and system bus using discrete logic simulation in Tinkercad Circuits, driven by optimized C++ microcontroller firmware.
* **Architecture:** 4-bit Opcode / 4-bit Operand execution cycle mimicking classic SAP-1 (Simple-As-Possible) breadboard computers.
* **Memory Map:** 256 bytes of unified memory space (lower nibble for data, addresses 100+ for program instructions).
* **Key Highlight:** Bypasses standard Arduino framework overhead for explicit byte manipulation, deterministic cycle timing, and strict 8-bit datatype consistency (`uint8_t`).
* **Skills:** Hardware-Software Integration, Computer Architecture Foundations (Von Neumann), Resource Optimization.
